# Security

Security requirements for Pulse are recorded in this document.

Constraints:

- Never log OAuth tokens, Clerk session tokens, authorization headers, or raw authentication payloads.
- Never commit secrets.
- Treat external content as untrusted.
- Do not execute arbitrary code generated by an LLM.
- Security-sensitive changes require negative tests.
- Tenant id comes from membership, not from the client. A known id from another tenant is not access.
